## 改善項目一覧（アナリティクス画面）

位置はスクリーンショット画像の座標（1600×900px）です。実際の画面は 1920×1080pt なので、pt に直すには約 1.2 倍してください。寸法は画像からの目測です。

---

### 1. 「コンバージョン」カードの左の内側余白を「訪問者」カードと同じにする
- **対象**: 上段に4つ並ぶ指標カードの左から2枚目、「コンバージョン / 3.2% / +0.4pt」のカード。その左端の枠線と、中の文字（「コンバージョン」「3.2%」「+0.4pt」）の書き出しのあいだの余白です。
  - 比べる相手（「こっち」）は左端の「訪問者 / 12,480 / +8%」カードの、同じ位置の余白です。
- **問題**: 「コンバージョン」カードだけ左の余白が広く、中の文字が右に寄っています。
  - 「コンバージョン」: 枠線(x≈542)から文字(x≈578)まで約36px（約43pt）
  - 「訪問者」: 約20px（約24pt）
  - 「平均滞在」「直帰率」のカードも約20pxで、「コンバージョン」だけが違います。上の余白は4枚とも同じに見えます。
- **期待する変更**: 「コンバージョン」カードの左の内側余白を「訪問者」カードと同じ値（約24pt）にする。ほかの3枚と揃えば完了です。
- **確信度**: 高

### 2. ヘッダー右上のベルアイコンを、ほかのアイコンと同じ大きさにする
- **対象**: 画面右上、タイトル「アナリティクス」と同じ行に並ぶ6つのアイコン（検索、ベル、受信箱、カレンダー、歯車、ユーザー）のうち、左から2番目のベル（通知）アイコン(x≈1166, y≈141)。
- **問題**: ベルだけがほかのアイコンより少し大きく表示されています。
- **期待する変更**: ベルアイコンの表示サイズを、隣の検索・受信箱などと同じにする。
- **確信度**: 高

### 3. 「平均滞在」カードのラベルの文字色を濃くする
- **対象**: 指標カードの左から3枚目、「平均滞在 / 2分41秒 / +12秒」カードの一番上にある灰色の小さいラベル「平均滞在」(x≈861, y≈220)。
- **問題**: ラベルの色が薄く、読みにくいとのことです。
- **期待する変更**: ラベルの文字色を今より少し濃い灰色にする（指示は「もう少し」なので、大きくは変えない）。
- **確信度**: 中。指した要素が「平均滞在」のラベルであることは確実です。ただ、どこまで変えるかが分かりません。画像で見る限り、4枚のカードのラベル（訪問者・コンバージョン・平均滞在・直帰率）は同じ灰色に見えます。この項目だけ発話に「だけ」がないこともあり、1つだけ変えると不揃いになりそうです。
- **候補**:
  - (a) 4枚のカードのラベルをまとめて濃くする（共通スタイルの変更）。こちらが有力と推測します。
  - (b) 「平均滞在」だけを濃くする。
- **ユーザーへの質問**: 「濃くしたいのは『平均滞在』のラベルだけですか。それとも『訪問者』『コンバージョン』『直帰率』も含めた、4枚のカードのラベル全部ですか。」

### 4. フィルターの「リピーター」と「モバイル」のあいだを、ほかのタグと同じ間隔にする
- **対象**: 画面下部、「フィルター」の見出しの下に並ぶタグ（すべて／新規／リピーター／モバイル／デスクトップ／広告経由）のうち、3番目「リピーター」と4番目「モバイル」のあいだのすき間(x≈491, y≈633)。
- **問題**: このすき間だけが狭く、タグ同士がくっついて見えます。
  - 「リピーター」と「モバイル」のあいだ: 約5px（約6pt）
  - そのほかのタグのあいだ（すべて–新規、新規–リピーター、モバイル–デスクトップ、デスクトップ–広告経由）: 約14px（約16pt）
- **期待する変更**: 「リピーター」と「モバイル」のあいだを、ほかのタグ間と同じ値（約16pt）にする。原因がこの2つのタグに付いた個別の余白や幅の指定なら、それを取り除いて共通の gap に揃えるのが望ましいです。
- **確信度**: 高
