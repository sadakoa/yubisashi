改善項目の一覧（アナリティクス画面。座標は画像のpxで、実寸は約1.2倍のpt）

---

### 1. 「コンバージョン」カードの左の内側余白
- **対象**: 上段に並ぶKPIカード4枚のうち、左から2枚目の「コンバージョン / 3.2% / +0.4pt」カード。その左の内側余白（カードの左の枠線から文字の左端まで）。指した位置は①(558, 250)で、カードの枠線と「3.2%」のあいだです。比較の基準は、左端の「訪問者 / 12,480 / +8%」カードの同じ位置（②(276, 249)）です。
- **問題**: コンバージョンカードだけ左の余白が広く、中身全体が右にずれています。目測で、コンバージョンは約37px（約44pt）です。訪問者は約20px（約24pt）、「平均滞在」と「直帰率」も約20pxです。
- **期待する変更**: コンバージョンカードの左の内側余白を、訪問者カードと同じ値にする（他の3枚と揃う）。ラベル・数値・増減の3行とも同じだけ左へ移ります。
- **確信度**: 高

### 2. ヘッダー右のベル（通知）アイコンの大きさ
- **対象**: 画面右上、タイトル「アナリティクス」と同じ行にあるアイコン6つ（検索・ベル・受信箱・カレンダー・設定・アカウント）のうち、左から2つ目のベル。位置は(1166, 141)で、虫眼鏡と受信箱のあいだです。
- **問題**: ベルだけが周りのアイコンより一回り大きく見えます。
- **期待する変更**: ベルを、検索・受信箱・カレンダー・設定・アカウントと同じサイズにする。並びと間隔は今のままにします。
- **確信度**: 高

### 3. 「平均滞在」カードのラベルの濃さ
- **対象**: 上段のKPIカードの左から3枚目で、「2分41秒」の上にある小さなグレーの見出し「平均滞在」。位置は(861, 220)です。
- **問題**: ラベルの文字色が薄いです。
- **期待する変更**: このラベルの文字色を少し濃くする。具体的な色の指定はありません。
- **確信度**: 高（指した要素は「平均滞在」で確実です。指したあとカーソルは「フィルター」見出しへ移っていますが、これは次の区間へ移る途中です。どこまで変えるかは不明です）
- **確認したいこと**:
  - 画像で見るかぎり、4枚のラベル（訪問者・コンバージョン・平均滞在・直帰率）は同じグレーに見えます。「平均滞在」だけでなく4枚とも濃くする意図でしょうか。1枚だけ変えると、ほかとの統一が崩れます。
  - どのくらい濃くしますか。目標の色や、トークン・段階の指定はありますか。

### 4. フィルターのタグ「リピーター」と「モバイル」のあいだの間隔
- **対象**: 画面下の「フィルター」見出しの下にあるタグの並び（すべて / 新規 / リピーター / モバイル / デスクトップ / 広告経由）。そのうち3つ目の「リピーター」と4つ目の「モバイル」のすきまです。位置は(491, 633)です。
- **問題**: この1か所だけタグ同士が詰まっています。目測で、ここは約5px（約6pt）、ほかのタグ同士は約13px（約16pt）です。
- **期待する変更**: リピーターとモバイルの間隔を、ほかのタグ同士の間隔と同じにする。後ろの「モバイル」「デスクトップ」「広告経由」はその分だけ右へずれます。
- **確信度**: 高
