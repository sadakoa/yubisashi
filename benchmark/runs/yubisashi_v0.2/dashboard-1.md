## 改善項目一覧（dashboard/B「アナリティクス」画面）

寸法は記録画像（1600×900px）を計測して出した近似値です。画面上の pt は画像の px を 1.2 倍した値です。review.md には「指した要素」（DOM の id や class）の情報がなかったため、コードで探すときの手がかりは見た目と周りの文字だけです。

### 1. 「コンバージョン」カードの左の内側余白
- **対象**: 画面上部に4枚並ぶ KPI カードの左から2枚目、「コンバージョン / 3.2% / +0.4pt」のカード。カードの左の枠線から中の文字までの内側余白です。指した位置は「3.2%」のすぐ左（区間1①）。
- **問題**: このカードだけ中身が右に寄っています。左の内側余白は画像上で約38px（約46pt）です。ほかの3枚（訪問者・平均滞在・直帰率）は約21〜22px（約25pt）です。ラベル・数値・増減の3行すべてが同じだけずれています。カードの大きさ、カード同士の間隔（約24px）、上下の位置はほかのカードと同じです。
- **期待する変更**: このカードの左の内側余白を「訪問者」カード（区間1②）と同じ値にする。
- **確信度**: 高
- **根拠**: 区間1「この①余白こっち②と同じにして」。①は「コンバージョン」カードの中、②は「訪問者」カードの中で、どちらもカードの左の枠と数値の間を指しています。

### 2. ヘッダー右上の通知（ベル）アイコンのサイズ
- **対象**: タイトル「アナリティクス」と同じ行の右端に並ぶ6つのアイコン（検索・ベル・トレイ・カレンダー・歯車・ユーザー）のうち、左から2番目のベルのアイコン（区間2①）。
- **問題**: ベルだけ大きいです。画像上で約19×20px（約23×24pt）あります。ほかの5つは高さも幅も約13〜16px（約18pt前後）です。
- **期待する変更**: ベルをほかのアイコンと同じ大きさにする。縦の中心もほかと揃える。
- **確信度**: 高
- **根拠**: 区間2「この①アイコンだけ少し大きい」

### 3. KPI カードのラベル「平均滞在」の文字色
- **対象**: KPI カードの左から3枚目「平均滞在 / 2分41秒 / +12秒」のカードで、一番上にある小さな灰色のラベル「平均滞在」（区間3①）。
- **問題**: ラベルの色が薄いです。現在は灰色で、画像上の最も濃い画素でも約 #96969A です。
- **期待する変更**: ラベルの色をもう少し濃くする。具体的な色の指定はありません。
- **確信度**: 中。指した要素が「平均滞在」のラベルであることは確かです。ただし、変える範囲がこのラベルだけかどうかを特定できません。
  - 計測すると、ほかのカードのラベル（訪問者・コンバージョン・直帰率）もほぼ同じ灰色です。「平均滞在」だけが薄いわけではありません。そのため、次の2つの候補があります。
  - 候補A（有力）: KPI カードの4つのラベルすべてを濃くする。共通のスタイルを変更します。
  - 候補B: 発話のとおり「平均滞在」のラベルだけを濃くする。この場合、ほかの3つと色が揃わなくなります。
- **補足**: この区間では、①で止まった後にカーソルが左下の見出し「フィルター」まで移動しています。止まっておらず発話もないので、次の区間へ移る途中の動きと判断しました。「フィルター」はすでにほぼ黒い文字です。
- **根拠**: 区間3「この①ラベルもう少し濃くしたい」

### 4. フィルターのタグ「リピーター」と「モバイル」の間隔
- **対象**: 画面下部「フィルター」の下に並ぶタグ（すべて / 新規 / リピーター / モバイル / デスクトップ / 広告経由）のうち、左から3番目「リピーター」と4番目「モバイル」の間（区間4①）。
- **問題**: この1か所だけ間隔が詰まっています。間隔は画像上で約4px（約5pt）です。ほかのタグの間はすべて約13px（約16pt）です。
- **期待する変更**: 「リピーター」と「モバイル」の間隔を、ほかのタグの間と同じにする。原因が「リピーター」の右マージンか「モバイル」の左マージンかは、画面からは判断できません。コードで確認してください。
- **確信度**: 高
- **根拠**: 区間4「タグの並びここ①だけ詰まってる」。①は2つのタグの隙間のちょうど上にあります。

## ユーザーに確認したいこと
1. **項目3**: 濃くするのは「平均滞在」のラベルだけですか、それとも4枚の KPI カードのラベル（訪問者・コンバージョン・平均滞在・直帰率）すべてですか。今は4つとも同じ灰色です。また、目標の色（例: 本文の黒に近い灰色）があれば教えてください。
2. **項目1（念のため）**: 「コンバージョン」カードの左の余白を揃えれば足りますか。中身が左揃えなので、右の余白が違うかどうかは画面からは判断できません。カード全体の内側余白をほかのカードと同じにする方針でよいかも確認したいです。
