## 改善項目一覧（アナリティクス画面）

数値は記録画像（1600×900px）で測った値です。画面上の値（pt）は、画像の値を1.2倍した近似値です。

### 1. 「コンバージョン」カードの左の余白
- **対象**: 上段に4枚並ぶ指標カードの左から2枚目、「コンバージョン / 3.2% / +0.4pt」のカード。カードの左の枠線から中身（ラベル・数値・増減）までの余白です。
- **問題**: このカードだけ左の余白が広く、約36px（約43pt）あります。ほかの3枚（訪問者・平均滞在・直帰率）は約20px（約24pt）です。
- **期待する変更**: 左端の「訪問者 / 12,480」カードと同じ左の余白にして、4枚の中身の左端の位置を揃える。
- **確信度**: 高
- **根拠**: 区間1。①（558,250）は「3.2%」の左の白い余白、②（276,249）は「12,480」の左の同じ位置です。

### 2. ヘッダーのベル（通知）アイコンの大きさ
- **対象**: 見出し「アナリティクス」と同じ行の右端にある6個のアイコン（虫眼鏡・ベル・トレイ・カレンダー・歯車・人型）のうち、左から2番目のベル。
- **問題**: ほかより一回り大きい。ベルは約19×20px、虫眼鏡・歯車・人型は約15×16pxで、約1.25倍あります。
- **期待する変更**: ほかのアイコンと同じ大きさにする。
- **確信度**: 高
- **根拠**: 区間1の③（1166,141）。1.5秒止まって「このアイコンだけ少し大きい」と話しています。

### 3. 指標カードのラベル「平均滞在」の色
- **対象**: 上段の指標カードの左から3枚目、「2分41秒 / +12秒」の上にある灰色の小さい見出しです。文字の一部がマーカーで隠れていますが、「平均滞在」と推定します。
- **問題**: ラベルの色が薄い。
- **期待する変更**: 文字色をもう少し濃くする。
- **確信度**: 中。指した要素は特定できていますが、変更の範囲がはっきりしません。
- **補足**: 4枚のラベル（訪問者・コンバージョン・平均滞在・直帰率）はどれも同じくらいの灰色（約#808080〜#89888E）で、このラベルだけが薄いわけではありません。ほかの指示には「だけ」が付いていますが、この指示には付いていません。そのため、4枚のラベルをまとめて濃くする意図の可能性が高いと推測します。
- **確認したいこと**: 下の質問1・2
- **根拠**: 区間2の①（861,220）

### 4. フィルターの「リピーター」と「モバイル」の間隔
- **対象**: 「訪問者の推移」グラフの下、「フィルター」の行に並ぶタグ（すべて / 新規 / リピーター / モバイル / デスクトップ / 広告経由）。そのうち「リピーター」と「モバイル」の間です。
- **問題**: この間隔だけ約6px（約7pt）しかありません。ほかのタグの間はどれも約15px（約18pt）です。
- **期待する変更**: ほかのタグの間隔と同じにする。
- **確信度**: 高
- **根拠**: 区間2の②（491,633）。カーソルは「すべて」から右へタグ列をなぞり、この2つの間の白い隙間で止まっています。

## ユーザーに確認したいこと
1. **（項目3）** ラベルを濃くするのは「平均滞在」だけですか。それとも4枚の指標カードのラベルすべてですか。今は4枚とも同じ灰色なので、1枚だけ変えると揃わなくなります。
2. **（項目3）** 濃さの目安はありますか（例：今の#888前後を#555〜#666くらいにする）。また、変えるのは色だけで、太さはそのままでよいですか。

ほかの3項目（1・2・4）は対象と期待する状態がはっきりしているので、確認なしで作業できます。
